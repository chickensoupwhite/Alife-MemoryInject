# Retromem 溯忆 (v5.1.12)

> *“就像旧日飞逝 / Like old times passing by.”*

**Retromem（溯忆）** 是面向 Alife 的独立角色记忆管理模块。它以只读方式读取官方记忆（默认 `L1`、`L100`），将对话流水提炼为结构化的“事实卡”，并将事实卡、索引与操作记录独立存储于角色的 `MemoryFacts` 中，从而避免重复摄入 `L2–L6` 压缩档。

---

## 一、 记忆提炼与多路召回

* **增量整理与压缩**：支持自动或手动调用模型，将新增内容提炼为结构化事实卡；模型调用失败时自动保留批次等待重试。支持压缩候选预览与手动压缩，自动压缩可独立开关。
* **多路混合召回**：结合关键词检索、时间检索、关系线索检索，以及 **“全库有效事实向量粗筛 + MiniLM 本地精排”**，能够召回无字面重叠的语义相关候选。
* **智能防打扰与主动检索**：自动判断当前语境是否需要触发召回，支持控制重复提醒、话题切换、触发间隔及近期记忆排除；同时提供主动记忆工具供直接查找。

## 二、 记忆治理与可视化

* **事实卡管理**：支持浏览、搜索、按**调用频率与调用情况**筛选，可查看来源与详情；支持直接编辑正文、软删除事实卡，并完整保留操作记录。
* **记忆审计**：自动提示重复、疑似冲突及过期候选。支持确认写入、合并、保留原卡、退役旧卡；提供多条批量确认、操作记录查看及撤回功能。
* **人物与实体画像**：提供人物、事件、事物三种视图，按主题归纳事实并区分“直接事实”与“共同事件”，附带原文证据与时间线；支持人工确认或排除待分类标签。
* **共现关系图谱**：展示人物、事件／主题、事物之间的共现关系。支持全库概览、搜索展开、加载更多、缩放平移、拖拽联动与松手回弹、节点聚焦与退出。

## 三、 索引维护、诊断与界面

* **索引与数据维护**：提供索引预览、普通重建、安全重建、备份与恢复功能；支持清理重复索引、维护软删状态与缓存更新，并在重建时自动重放已有的审计处理决定。
* **调用统计与诊断**：可查看已确认调用、自动注入、工具调用、近七日调用及统计覆盖范围；支持检查侧车、向量预热与精排状态，并提供召回结果解释。
* **其他辅助工具**：支持查询未完成事项／牵挂、提取来源原文、折叠长输出并按 ID 取回；内置历史清理统计工具（当前仅统计插件合成的历史消息，不执行删除）。
* **界面与主题**：采用玻璃面板、磁带样式事实卡与轻量动画，精调参数默认收起。内置七套主题（默认“迈阿密落日”），包含最新加入的“地平线”、“上浅下深渐变”与“霓虹鸡尾酒”配色。

## 四、 效果边界说明

为便于合理预期，当前版本存在以下机制边界：

1. **向量与精排范围**：全库向量覆盖率取决于后台预热进度；本地精排单次最多处理 24 条候选，不对全库逐条计算。
2. **调用统计范围**：调用次数与最近调用时间自本版本启用时开始累计，此前历史调用不计入；刚启用时排序区分度有限。
3. **语义召回能力**：MiniLM 已支持部分中文语义改写，但仍可能存在漏召回；当精排服务不可用时，系统会自动回退至关键词检索结果。
4. **画像与图谱定位**：实体画像是基于证据的主题归纳，不等同于深度人格分析；图谱连线仅代表“共现关系”，不代表因果关系。
5. **审计自动化程度**：自动审计仅对严格满足条件的重复项执行合并，近似重复与疑似矛盾主要交由人工确认。
6. **模型与 API 依赖**：本地向量计算与精排无需外部 API，但前期的“记忆整理”仍依赖 Alife 中配置的模型。
