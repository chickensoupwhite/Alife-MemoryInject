# Mao.MemoryInject · 记忆回忆提示

给 Alife 角色装一层"嗅旧账"的鼻子：主人说话时，在后台把这句话跟角色的记忆档案比对一遍，
命中相关的旧账就在消息末尾轻轻提示一句——只告诉你去翻哪几份，不把内容塞进上下文。

## 和官方 Alife.Function.Memory 的区别

- 官方记忆：命中"还记得""以前""上次"等**关键词**才提示，不认语义。
- 本插件：**不看关键词，每句话都做语义比对**，像意思就够了。两条可并存，也可只留一条。

## 行为原则

- **只读不写**，绝不改动记忆档案。
- **命中才提示**，没有相关旧账时一句话都不加。
- 任何异常一律**放过原消息**，绝不影响正常对话。
- 语义检索有**毫秒级硬上限**；侧车没就绪或超时立刻退回关键词匹配，绝不拖慢主线程。

## 依赖

- `Alife.Function.FunctionCaller`
- 需要本机 Python 及 `torch`、`transformers`，并已下载 `BAAI/bge-small-zh-v1.5` 向量模型
  （与官方记忆插件同款）。未就绪时插件自动退回关键词模式，不会报错。

## 配置

见插件配置面板，逐项都有说明。常用：启用开关、是否用语义检索、记忆目录、相关度阈值。
